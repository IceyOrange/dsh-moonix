# moonix

同步 moonix App 中的录音文件、逐字原文和摘要，还能查看个人待办，帮你快速回顾会议重点，找回关键信息。

## 回顾重要会议

查找会议记录，阅读摘要与逐字原文，梳理讨论重点和关键结论，让重要信息更容易找回。

## 跟进个人待办

查看你在 moonix 中的待办，了解哪些事项还未完成，并请 AI 按优先级整理。

## 试着这样问

- 帮我总结本周在 moonix 记录的会议，列出关键结论。
- 查看 moonix 中我还没完成的待办，按优先级整理。

## 开始使用

连接你的 moonix 账号后即可使用。首次使用时会打开浏览器授权页，请按页面提示完成登录和授权。若浏览器未自动打开，请使用 DeepSeek 提供的授权链接；授权后返回对话，确认连接并了解可用功能。

moonix 插件以只读方式访问你的记录和待办，不会创建、修改或删除 moonix 中的内容。
